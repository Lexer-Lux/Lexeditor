- **Voicedrew11 / Verdite2 contributors** — Existing PC port, native settings
  schema and limits, source-mod integration and game-routine research.
  <https://github.com/Voicedrew11/verdite2>
- **flaffy / RecompOne contributors** — Native C# source-mod compilation, events,
