# Red Dead Redemption third-party credits

Lexeditor's Red Dead Redemption plugin reads RDR1 archives and string tables using the following references.

## Attributions

- **MagicRDR contributors** — Reference and separately installed tool for Red Dead Redemption archives. <https://github.com/Foxxyyy/Magic-RDR>
- **CodeX.Games.RDR1 contributors** — Public RDR1 STRTBL/RPF6 format research consulted for independently implemented string-table compatibility. <https://github.com/Foxxyyy/CodeX.Games.RDR1>
- **K3rhos / RedHook** — External RDR1 runtime prerequisite. Lexeditor links to the official download and does not redistribute RedHook files. <https://www.nexusmods.com/reddeadredemption/mods/192>
