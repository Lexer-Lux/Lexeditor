This folder is where a Rebirth mod keeps its ReShade preset.

Put the preset .ini here. Any shaders you wrote yourself go in a "shaders"
folder beside it. Shaders from a public repository are never copied in: the
mod names the repository instead, because several of them may not be
redistributed, and the by-hand install note lists what to install.

Write that note from the Tweaks page. It tells anyone who downloads the mod
what to install and where the preset goes, without mentioning Lexeditor.
