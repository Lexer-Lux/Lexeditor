# Lexeditor FFX/X-2 project

Lexeditor creates `efl/x/` and `efl/x2/` when this project is initialized.

- `efl/x/` mirrors Final Fantasy X VBF paths for Fahrenheit's External File Loader.
- `efl/x2/` mirrors Final Fantasy X-2 VBF paths.

Keep installed `FFX_Data.vbf` and `FFX2_Data.vbf` unchanged; extract source files through Lexeditor before editing them here.
