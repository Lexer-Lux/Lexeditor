- Plus button / empty slots: a table that knows its empty slots gets a live + that opens the next empty one, plus HIDE EMPTY. In FF8 only Encounters > Formations has empty slots (176 of 1,024); every other table's data has none (Weapons 'None' and Junction 'None' are entries the game itself uses).
- Region (cell) details: one cell panel on Map and Cells lists sky colours, draw points, field->world, ground types and encounters. World->field can't be listed: that table has no world position.
- Ground types: ID and Name now use the standard list columns. Edit the name in the detail heading and Save; it is a project label, not a terrain-behavior change. Linked ground labels use the edited name. Clear it to restore the default from Deling's notes. One ground type can use many textures.
