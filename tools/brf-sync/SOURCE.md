# BRF Sync Tool

Lexeditor bundles `brf_sync.exe` as a separate command-line program for
read-only Mount & Blade: Warband BRF conversion.

- Upstream: https://github.com/markpryk/brf_sync_tools
- Release: `brfsync` (`brf_sync_0.8.exe`)
- Source commit: `567fd4172006a30da0152e42f9182ec797446ba2`
- Binary SHA-256: `e04f66bfa75ef68dc8e088eca267ff67dc32caf9fbc775e31d3e585ebca405c9`
- License: GNU General Public License version 2

`source.zip` contains the exact upstream source snapshot. `LICENSE` contains
the upstream license. Lexeditor calls the executable as a separate process and
does not modify Warband BRF files.
