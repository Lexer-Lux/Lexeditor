# 864 — Tool Belt (DS1)

DS3-style tool belt as a DS1 tweak mod. Issue stays `actionable`: v4
(mod 0.7.0-v4) is built and in Lexer's library, 74 mod tests green;
not yet seen in the game (v3 neither).

## Requirement (Lexer, 2026-10-17, after seeing v2 render)

- One panel: four squares directly under the four category icons, a
  label on the left naming the hovered row (the category, or "Tool Belt"
  on the belt row), the key guide fixed at the bottom.
- Remove the "Browse and use items" help line and the L/R (HOME/END, < >)
  prompts.
- Squares are little textured squares; later, item icons over them.
- The belt gets its own key guide.
- Assignments survive a reload.
- Later: Y opens the inventory on consumables; A there puts the item in
  the slot.

## Requirement update (Lexer, 2026-10-22)

Five wide, both rows. The new fourth top-row entry is Write (DS3 style:
opens the message writer). The orange soapstone goes: not buyable, and not
in the inventory when already owned.

## v3 (built 2026-10-20)

- Layout: R00 plate under everything (new layout `before`), R00's BG,
  help line and R00-00's `category_LR` instance moved off screen, key
  guide moved to the bottom and widened; R00-00 gains four category
  title clones (message text, repointed ids), the "Tool Belt" label,
  four squares (HUD dark plate), glows (HUD item light), counts and the
  item line. Clones gained `from` in Lexeditor.
- Island: category from channel 0x4B shows one title; the belt row shows
  the label, the selected glow and the item name; entering writes the
  belt's guide (tags, dynamic string) into `Ins_keyguid/text_help0`;
  leaving sets `[dialog+0x248]` so the game restores its own guide. A menu
  reopened after 0.25 s starts outside the belt (`_Xtime_get_ticks`).
- Saving: squares are 10-bit event-flag values at 10000100 + 10 i, read
  each frame and written on Remove/Switch through 0x4F2590/0x4F24B0, with
  a read-back (debug 0x400 ok / 0x800 failed; 0x100 flags readable, 0x200
  not ready). Group 1's global block; no references in events, talk
  scripts or params. NG+ behaviour of that block is unknown.
- DLC goods names: GoodsName patch bank `+0x58` after `+0x380`.
- State 0x1A24D40-0x1A24DA0 (UI Rework now holds 0x1A24E80-0x1A24F80).
- Composes with every library mod: 19 native descriptions, 7 layouts.

## v4 (built 2026-10-22)

- Top row: Inventory, Equipment, Status, Write, System. The category
  channel keeps the game's 0-3; Write is 4. The island walks Left/Right in
  display order (0, 1, 2, 4, 3), writes the channel and sets the root's
  `0x249` refresh, whose `cursor0_%d` lookup lands on the layout's
  `cursor0_4`. System's icon/highlight/cursor move one slot right; the
  Write icon is `Icon/EquIcon_2082` (the soapstone's item icon), dimmed,
  with a full-colour copy shown while hovered. Title "Write message"
  (Menu_others 143022). Key_guide 10005 does not exist, so on Write the
  island sets property 6001 = 10001 itself.
- Write = `0x688710`, the game's own writer opener (channel 18 -> T04);
  found through the menu scripts (Lexeditor's new ESD reader) after the
  native routes stalled. No soapstone needed.
- Soapstone: param row ShopLineup 1100 equipId -1 (the only source;
  `tools/build_shop.py`); an owned one is removed on each fresh menu via
  `0x749310(inv, index, -count, 1, 0, 1)`.
- Five squares (flags 10000100-10000149). Composes with every library
  mod: 19 natives (190 hooks), 7 layouts, 8 param mods.

## v4 seen live (2026-10-22), 0.7.1

Renders: one panel, five-entry top row with the soapstone icon, five
squares, game-text titles, button glyphs in the key guide. Two findings:
- Write showed "?KeyGuide? ID: 10005": the root's state machine sets the
  refresh byte on its own transitions, and 0x66F3A0 asks for 10001 + 4.
  0.7.1 ships `msg/ENGLISH/menu.msgbnd.dcx` with Key_guide and
  Single_line_help 10005 (both table copies; merged by entry, no conflict
  with Armor Rework or Mana System). Other languages still lack them; the
  island's own 10001 override remains as a partial fallback.
- "Lots of empty space, weird shape": panel now (688,48)-(1164,242),
  squares at y 120, item line 171, guide 201-236.

## Live check (needs Lexer)
