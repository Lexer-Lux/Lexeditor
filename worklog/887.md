## Native evidence

Judge-cancel design (no input swallow): the press reaches the game, the
judge island cancels the player's melee R2 evaluations while charging,
and the input island injects a one-poll synthetic press on release; the
re-fire evaluates the normal or the +5 row by hold time. Bows/shields/
casts/fists/NPCs/menus/Y+R2 pass through by construction; keyboard R2
passes through via the padHeld gate (vanilla until step 3).

- judge_cancel at 0x35989F (7 bytes `75 35 b8 d3 4d 62 10`), below the row
  lookup: r14 = character, esi = judge, edi = variation, ebx = key. The
  earlier 0x3597C0-entry candidate was dropped (no variation in hand
  there). Bow guard settled as the baked per-group eligibility table, so
  no runtime equip/ParamMan reads exist anywhere.
- r2_input_poll at 0xE1C1BF (6 bytes `85 c0 75 11 8b d3`), post-call in
  the 4-pad XInput poll loop; pad 0 only, stack state at rsp+0x20.
- WorldChrMan static 0x1C77E50 (+0x68 PlayerIns). State: 24 bytes the mod
  owns at 0x1A24C20-0x1A24C38, past .rdata (grown to 0x787C38, writable and
  zero-filled by the loader), just after Better Binoculars' block. It used
  TEB TLS slots 61-63 until 2026-10-11, but a running DSR allocates all 64
  TLS slots, so the islands would have overwritten other code's per-thread
  data. Composes with every other buildable native mod in the library.
- Islands are leaf routines assembled by keystone from `script/islands.asm`
  (521 code bytes together), embedded into `native_patch.py` by
  `tools/rebuild_islands.py --write-embed`; tests reassemble and refuse
  drift. Spec validates and composes onto the supported build (SHA
  `a45aaa36...`); hooks land in the islands and all 8 relocations resolve
  (verified in the composed bytes).
- Threshold counts polls at 60 Hz (1500 ms = 90 polls); stretches on frame
  drops. One-poll inject assumes per-frame edge consumption.
- Dead ends kept out: action dispatch (~0x2C1xxxx, no pdata, Arxan) holds
  no hooks; stamina-write sites are shared regen ticks; no merge point for
  pad/kb/mouse exists in clean code.
