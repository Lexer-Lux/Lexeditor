## Contracts and current evidence

KF3 already implements native geometry distance, fade, and enhancement distance
separately. Its in-game Original/Enhanced row couples geometry and fade; replace
that combined row with independent controls, using the existing persisted keys:

- `kf3.renderdistance`: float, default16, 0 means the game's changing radius,
  positive values1..30. Values below the native radius do not reduce it.
- `kf3.renderdistance.fade`: float, default3, 0 off, positive0.25..8. The smooth
  fade checkbox reads positive as on; enabling preserves an existing positive band
  or sets3. Do not invent a second boolean store for this fact.
- Native booleans elsewhere are numeric0/1, unlike KF2's True/False convention.
- The renderer caps depth before65,024 units; retained GPU geometry supports the
  existing distance path. Packets/reflections retain native reach, and creatures
  retain their activation limits. Atmospheric fog is independent.
