## What the mod does

One 580-byte island replaces the per-frame R3 call (0x24FCFB): it gates
on player/UI/menu/camera state, reads R3 over XInput pad 0, times the
hold with QPC, and past the threshold (default 350 ms, setting 100–2000)
restores the press's lock request and enters aim via SetAim. Release
leaves it. A 35-byte island replaces the cast gate (0x397412) and opens
it only while owned. Owned state (stamp, frequency, flags) lives in
`.rdata` grown 0x787C00 → 0x787C20. Short taps, menus, death, missing
controllers/players and manual aiming all stay native.

## Evidence

- 35/35 tests pass with the exe named (15 x64-execution scenarios in
  `tests/test_better_binoculars.py`, 20 package/integration in
  `tests/test_better_binoculars_mod.py`), including side-by-side compose
  with better-casting. See the mod's README/sources/verification files.
- The checks caught three genuine mod bugs before any game run: two
  RIP-relative+immediate instructions the composer cannot express (the
  spell gate would never have opened), an RAX clobber in the gate, and
  wrong gate branch targets (allow sat in hook pad = INT3; taken was
  mid-instruction). Correct targets 0x39741F/0x397550 verified by
  disassembly of the pinned exe.
- v1 enters the game's own aim state, not the item's SpEffect: no
  ID-switched binocular handler exists (behavior is data-driven, no
  static entry), so true binocular view without equipping is unreachable.
