## Design (verified statically)

One 895-byte stateless island hooks the frame CALL at RVA 0x39761A (pad in
RCX, controller in RDX), displacing the call to 0x391230, which runs
through a tail call. Each frame it checks local player, HP, inhibit flag,
context, UI state, right-hand weapon kind 8 (catalysts, talismans, flames,
read from the installed params via the plugin's own reader) through the
native resolver, and saved/actor assembly agreement. It writes the selected
attunement index to EquipMagicData+0x78 (the same field the game's own
spell-switch writes) and reroutes R2/L1/L2 through the native weak-action
pad bytes; bare R1 only reselects. Native left/right admission gates are
mirrored, so unadmitted presses pass through untouched.

Hook bytes, call target and register setup were read back from the
fingerprinted executable (size 50286344, sha256 a45aaa36…) at build time.
The site differs from Later-Game Ammunition's, so the two compose.
