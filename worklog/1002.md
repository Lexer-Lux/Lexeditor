Ordinary source mod at `D:/Documents/Mods/kf1/xp-bar`, id `kf1.xp-bar`. It reads
native EXP, level and thresholds without writes. One removable HUD listener draws
a two-pixel full-display bottom track/fill. The generic runtime HUD event is in
the separately pushed/pinned runtime recorded in worklog/999.md.

installed-host bar were rendered and viewed with private cards. Existing game
snapshots precede ImGui, so a temporary after-host-render probe was necessary;
