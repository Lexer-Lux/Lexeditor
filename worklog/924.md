# 924 — Tabbed warp UI (owner: 924 worker)

## Requirements (from the issue; scope confirmed with Lexer)

- Recreate DS3's actual travel pattern in DS1: area tabs (left/right),
  each tab listing only its area's bonfires.
- One text tab per warp area (about 15, cycled); no tab icons.
- A vista panel showing a placeholder image per area; Lexer supplies
  real screenshots later.
- Empty tabs skipped or hidden; destinations, unlock, selection and
  travel preserved; behind the warp-ui-rework tweak (vanilla when off).
- Lexer decisions: placeholder vista (not blank, screenshots later),
  text tabs, one tab per area.

## Design (approved by nobody yet; matches Lexer's answers)

- 16 tabs from the 21 records, in #729 journey order (its ORDER
  flattened): Firelink [2000], Parish [2015,2001], Depths [2014],
  Painted World [2016], Catacombs [2020], Tomb [2017,2007], Demon
  Ruins [2006], Ash Lake [2008], Anor Londo [2002,2003,2004], Abyss
  [2005], Archives [2018], Crystal Cave [2019], Sanctuary Garden
  [2009], Oolacile Sanctuary [2010], Township [2011,2013], Chasm
  [2012].
- Strip: 5-slot scrolling window above the list (y 131-159), selected
  tab centred, labels rewritten per switch; fixed gold underline
  under the centre slot (order-free, no move APIs needed).
- Labels: abbreviated `Place_name_` 2100-2115 in the mod's msgbnd
  (Firelink … Sanct. Garden/Ool. Sanctuary … Chasm, all ≤14 chars);
  vista caption shows the full area name (vanilla ids 1020…1214).
- Vista: tinted flat sprite copy (`I01 blackout0_0`, stretched; flat
  so stretch- and tile-safe) at x 560-1180, y 180-529 + caption
  beneath. Real per-area art is a later TPF-texture job (follow-up).
- Native: one `warptabs` island + three E9 hooks. H1 @`0x6ED7C6`
  (19 B) selects the tab's table + count (replaces the leas AND the
  hardcoded `mov r14d, 0x15`). H2 @`0x6EDD60` (10 B) polls L1/R1
  with edge detect, skips empty tabs (flag test `0x4F57A0` +
  current-bonfire exclusion), rebuilds via `0x6ED740`, resets
  cursor/scroll, rewrites labels/caption (NULL-guarded, cached
  controls). H3 @`0x6ED545` (8 B) scans the first non-empty tab at
  every open and sets labels pre-show (no flicker). Unwind: H2/H3
  share one blob (same prologue); H1 is call-free. Island asm is
  authored `.asm`, Keystone-assembled at dev time, frozen bytes in
  `native_patch.py`, roundtrip test enforced.
- Layout: `layout/warp-ui-rework.json`, 8 nodes (`warp_tab0`…`4`,
  `warp_tabhl`, `warp_vista`, `warp_caption`), deployed statically
  like better-details. Key-guide L1/R1 prompt and tab-switch sound
  are v1 skips (noted as polish).
- Empty tabs: skipped while cycling; all-empty is vanilla-empty
  (early game from the only bonfire) and safe (bounds-checked
  everywhere).
