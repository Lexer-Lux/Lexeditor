# Worklog: Github 42

## GitHub #42 more gunsmiths feasibility — 2026-08-05

`shop_gunsmith.c` recognizes `SHOP_BLK_GUNSMITH`, but extracted
`persistentcharacters.meta` has complete owner/model/schedule records only for
Valentine, Rhodes, Saint Denis, Annesburg and Tumbleweed. A public Blackwater
Gunsmith map mod supplies the missing physical shop and demonstrates that a
Blackwater port is feasible. It does not make Strawberry or Armadillo a data
toggle: those still need a building/interior choice, persistent merchant,
schedule, shop binding, blip, hours and hostility/death recovery. The research
was reported on GitHub #42 and the issue remains exploratory pending Lexer's
decision about whether and where to add one.
