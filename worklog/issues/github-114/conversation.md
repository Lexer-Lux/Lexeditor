Installed ASI: 144FDA14CFF5426F1406FB8909E89A0399C50F7C6A952F7F722E2A3ADAD24E19. The issue remains open with only unfeasible: auto-center retains an input-edge implementation, while the requested in-map MMB/R3 recenter remains impossible because the script thread does not tick while MAP is open.
