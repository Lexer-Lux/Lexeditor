# Worklog: Github 74

## GitHub #74 recurring exhaustion-like fade — 2026-08-05

The prior #203 diagnosis was real but incomplete. Its core-value oscillation was
removed; the latest `GameplayTweaks.reserve.log` confirms player cores now move
monotonically. The visible fade survived because the rejected standalone
`CoreVignetteRamp.asi` was still installed and active.

This was a deployment contradiction, not an unidentified engine effect:

- `CODEX.txt` already said CoreVignetteRamp was dropped, its vanilla low-core
  AnimPostFX has an unavoidable pulse, and it must not be reinstalled.
- `Install-When-RDR2-Closes.ps1` nevertheless copied the ASI into the game root
  on every deferred GameplayTweaks install.
- The live `CoreVignetteRamp.log` was still updating in this session and showed
  `running=1` almost continuously, with Stamina strength around 0.63–0.96 and
  Dead Eye strength around 0.72. That is the exact exhaustion-like haze Lexer
  reported, generated by our standalone effect mod.

Removed both CoreVignetteRamp install calls. The installer now moves any live
`CoreVignetteRamp.asi` and `.ini` into the existing game-root
`mod storage/CoreVignetteRamp` folder after RDR2 exits, keeping them recoverable
but outside ScriptHook's loader path. Wrote `[General] Enabled=0` to the current
game-root INI as an immediate defensive disable; the loaded ASI may require the
restart because its configuration is not proven to hot-reload. Replaced the
already-running old deferred installer with the corrected watcher (PID 406808),
so it cannot reinstall the rejected ASI on exit.

No GameplayTweaks code change or rebuild was required for this cause. Runtime
acceptance is one complete restart with no `CoreVignetteRamp.asi` in the game
root and no renewed `CoreVignetteRamp.log` output.
