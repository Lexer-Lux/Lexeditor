## Problem

The physically rigged belt lantern can clip through Arthur's leg during movement and with some clothing or poses.

## Current boundary

The accepted lantern is a rigid physical prop joint. No proved current RDR2 native or asset path provides reliable clearance against the animated leg and coat. Preserve the working physical rig. Revisit this only if a sanctioned collision, cloth, or custom-asset path is proved.
