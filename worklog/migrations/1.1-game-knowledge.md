# Lexeditor 1.1 game-knowledge consolidation

Lexeditor is the canonical development repository for all supported games and Lexer mod projects. The standalone `Lexers-Mod-For-*` repositories are distribution/storage mirrors only.

## Consolidated for 1.1

- Merged the completed FF8 backlog/runtime branch and the completed FF9 working branch into the 1.1 integration line while preserving current shared/global work.
- Retained FF9's new Memoria integration codex and issue worklogs in Lexeditor.
- Preserved the newest RDR2 runtime-session worklog deltas under the corresponding central issue histories (#120, #181 and #357), plus the two superseded PR summaries under the RDR2 import archive.
- Earlier RDR2, Warband and Bannerlord Codex/Worklog migrations remain authoritative; their historical source revisions and verbatim archives are recorded in `worklog/migrations/game-knowledge.json` and `worklog/imports/`.

## Standalone mod repositories

Every active `Lexers-Mod-For-*` repository now carries a storage-only `AGENTS.md` directing agents to Lexeditor for editing, issues, research, tests, Codex and Worklog material. Agents are explicitly told not to recreate local `codex/`, `worklog/`, Codex/Worklog text files, project-memory files or issue logs.

Migrated knowledge stores were removed from the RDR2, Warband and Bannerlord storage repositories after their central copies were verified. The FF8 storage repository contains the synchronized finalized runtime payload rather than development notes.

Future development documentation belongs here. Standalone repositories should receive only finalized distributable artifacts and the storage-only agent pointer.
