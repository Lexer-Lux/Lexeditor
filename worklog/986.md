## Implemented initial slice

- `plugins/kf1`: detected port, shared shell, shared Mods tab, Settings, Credits
  and an honest partial Data Map. Original disc families and saves are not
  editable. No copied binary payloads, disc bytes or generated source committed.
- Native numeric View distance and independent Smooth distance fade. Both use
  existing native `interface.ini` keys; Lexeditor edits those same settings,
  preserves unknown keys/ImGui sections and uses optimistic hashes. Settings
  writes refuse a running `KingsField1.exe`. Backups are bounded to original and
  previous versions.
- View distance is 0 for the original stencil or 8–30 for an extension. Original
  stencil cells remain. The inherited 30-cell cap stays below the renderer's
  16-bit depth plane. **Original fog is black at roughly 9.17 cells**; this limits
  visible distant detail. Fog mode and Enhancement distance are different
  shading controls, and are not relabelled as view distance or fade.
- Requested preset applied to installed native settings: RT/RB attack, LT/LB
  equipped spell/item, Cross/E interact, Circle/Left Shift held runs, Triangle/Tab
  menu, Square/Q equipped item/spell (including map). Cross confirms and Circle
  backs out in modal menus. Start/Select preserved; F1 Input can rebind.
- Hold-to-run is built into port controls, not an enabled mod. It uses unused
  R3 and scales the game's own collision movement by two; turn rate is unchanged.
- This archived port has no Remaster Editor. F2 belongs to the optional existing
  Debug Tools mod, which was not enabled in the player's setup.
- Native source mods load directly from the shared library through `mods.root`.
  Existing native IDs, dependency handling and hooks are retained. Duplicate IDs
  are rejected. Arbitrary hook compatibility remains per-mod work; the adapter
  remains explicitly unverified for general distribution.
