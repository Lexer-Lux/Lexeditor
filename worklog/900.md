# 900: Later-Game Style Backstabs

## Requirements

DS3-style backstab attempts in DS1 as a tweak: marginal R1s behind an
enemy play an attempt that can miss instead of instantly snapping both
characters into the critical. Vanilla behavior with the mod disabled.
Lexer's note on the issue: do not assume the technical mechanism, check it.

## State

Delivered as a data mod at `D:\Documents\Mods\ds1\backstab-attempt`
(0.2.0-unfinished). The mechanism turned out to be data, not code: the
backstab trigger zone lives in ThrowParam (dist 1.5 m, back-cone 0..60
deg on all 70 uniform rows; 2.5 m / 0..25 on the giant-tusk pair). The
mod scales that zone x2/3 distance, x1/2 angle on all 72 backstab rows
(normal + Hornet enhanced, player + per-enemy victims): 220 bytes
changed, everything else in the archive vanilla. Ripostes, plunges,
enemy grabs, damage, stamina, animations and vulnerability untouched.

The 0.1.0 native design (hook the trigger in the executable, refused to
build) is dropped; git history keeps it. Agent-side checks are green
(8/8 package tests: pinned zone, vanilla-diff confinement, rebuild
byte-identity, zero-conflict merge, disabled-means-vanilla). Stays
`actionable`: in-game acceptance has not run, and a hardcoded press
check would send this back for the scoped native slice (sources.md has
the protocol and the decision point).

## Evidence

Read from the installed Remastered game with the repo's own readers:

- Judge-500 BehaviorParam_PC/AtkParam_Pc rows per melee variation are
  the backstab (throwFlag 2, x2.0 corrections, own 0.4 m hitbox);
  variations without judge 500 are exactly the non-backstabbing weapons
  (bows, catalysts, whips, shields).
- ThrowParam row 1 (PC-on-PC backstab): dist 1.5 (+8), cone 0..60
  (+12/+16), attacker anim 3400 (+36), victim anim 9000 (+40).
- Angle-window reading confirmed by contrast: backstabs 0..60, ripostes
  90..180 (front hemisphere, 62 rows), plunges 0..180 + tall vertical
  band + 10 m (12 rows), tusk pair 0..25 (2.5 m dist).
- Enhanced (Hornet) rows differ from normal twins only in paired anims
  (3401/9420) + one flag byte: same zone, so uniform scaling is safe.
- Vulnerability is data: no PC-on-victim row means unbackstable (demons,
  dragons; Gwyn riposte-only matches the game).
- NOT verified: victim snap at R1 press vs at judge-500 hitbox connect.
  The mod is safe under either (moves only the selection boundary).
