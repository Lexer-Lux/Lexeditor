#85(b) rifle clipping. Answered the actual question: Story Mode NEVER calls
DRAW/TASK_PLAY_ANIM for pickups — it uses `_TASK_ITEM_INTERACTION`, and the
interaction data carries rifle-aware variants (17 distinct *_LEFT_HAND_RIFLE
states in the strings dump; the mask code here already uses
MASK_ON/OFF_LEFT_HAND_RIFLE). Our casing pickup plays kCasingAnimDict
"mech_pickup@system@rh" full-body via TASK_PLAY_ANIM with no weapon awareness.
BLOCKED on data: `LEX_CASING*` has ZERO entries in iteminteractioninfo.meta
(grepped), so START_ITEM_INTERACTION has nothing to play. PROPER FIX = author
casing entries in iteminteractioninfo.meta modelled on an existing small pickup
that has both right-hand and LEFT_HAND_RIFLE variants. INTERIM: detect a longarm
via attach points 9/10 and skip the wrong-handed reach, granting after 120 ms
instead of 650 ms.

#116 crouched 360. Mechanism: forced aim lets the camera yaw freely while crouch
pins the lower body, so at release the upper body unwinds the accumulated
aim-vs-body delta alone, and a large delta unwinds the long way — a full sweep
over a static lower half. FIX: in the release branch, read
GET_GAMEPLAY_CAM_RELATIVE_HEADING, normalise to +/-180, and if |delta| > 25
degrees SET_ENTITY_HEADING(ped, heading + delta) plus
SET_GAMEPLAY_CAM_RELATIVE_HEADING(0) BEFORE clearing forced aim, so there is no
delta left to unwind. Standing, delta is small and the branch is skipped. Logs
the delta to the binoculars log.

#169(c). `motionGain` was set to 1.0 when `inputMagnitude < 0.10f` — full speed
below the deadzone — while deliberate input above it ramped from 0 through the
blend. Stick drift or a stick returning to centre therefore drove him at full
speed ("keeps climbing when you stop"), and gain was discontinuous across the
threshold. Now 0.0 below the deadzone, and the movement vector is zeroed there
too. (a)(b)(d)(e)(f) untouched.
