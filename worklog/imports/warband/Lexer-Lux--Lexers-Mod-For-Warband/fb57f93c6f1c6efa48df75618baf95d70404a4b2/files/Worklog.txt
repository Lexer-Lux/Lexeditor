VERIFICATION TECHNIQUE THAT WORKS
================================================================================
To prove a source change actually reached the game, diff our compiled .txt
against Native's and look at which integer tokens moved:

  $o=Get-Content 'Module\menus.txt'; $n=Get-Content '<Native>\menus.txt'
  compare line by line, token by token

CAVEAT, learned the hard way: adding any inline @"..." string anywhere in the
source shifts the shared quick_string id table, so EVERY later reference shifts
by one and the diff looks enormous. Those 1585267068834414947 -> ...948 diffs
are benign id renumbering, not damage. Look for small integer changes.
