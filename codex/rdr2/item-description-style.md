# Item and consumable description style

This is the durable style guide for LEXEDITOR and MyOverhaul item text.

### Protected text

- `Deprecated.` means intentionally deprecated. Leave it exactly that way.
- Never replace user-authored text in bulk. Propose changes separately unless
  Lexer explicitly asks for a rewrite.
- Blank text is not permission to generate text for every item automatically.
- Preserve jokes, odd facts, blunt notes, and deliberately unusual phrasing.

### Voice

- Keep descriptions short enough for RDR2's radial-menu panel, normally one or
  two compact sentences.
- Write the particular item, not a reusable template with nouns exchanged.
- Favor memorable facts, period flavor, dry jokes, warnings, practical uses,
  provenance, or sensory details when they genuinely distinguish the item.
- Avoid restaurant-menu prose, sales copy, generic praise, and predictable
  adjective-heavy openings.
- Do not force every description to state every mechanical effect in prose.
  The effect icons and editor contain hard data; text should add character or
  clarify an important mechanic.

### Variation

- Do not repeat the same gain/loss verb across neighboring items.
- Useful mechanical vocabulary is a floor, not a template: takes the edge off,
  settles, sates, fills, refreshes, clears the head, wakes, dulls, dries out,
  leaves thirsty, tires, or fortifies.
- Vary structure as well as synonyms. Use fragments, observations, historical
  facts, warnings, jokes, and direct mechanical statements where appropriate.
- Read a batch together before saving it. If the rhythm or sentence pattern is
  obvious, rewrite the batch.

### Terminology

- Health Core is hunger; Stamina Core is thirst; Dead Eye Core is wakefulness.
- Outer bars are Health, Stamina, and Dead Eye. Do not call a core refill a bar
  restoration.
- Mention horse effects when they matter and are not obvious.

### Review checklist

1. Is the existing text protected or deliberately authored?
2. Does this sound specific to the item?
3. Is it shorter than the current formulaic version?
4. Does it avoid repeating nearby phrasing?
5. Are any mechanical claims exactly supported by the catalog effects?
