# Internal knowledge

Use one Markdown file per topic for confirmed facts about the games and editor.
Search by game, format, or feature before investigation. Record the source of
each fact. Do not treat a past build or test result as a current fact.

Issue attempts and pending verification belong in
`worklog/issues/github-<number>.md`. Historical handoffs are in `worklog/legacy/`.
GitHub issues contain the short request, status, and actions needed from Lexer.
